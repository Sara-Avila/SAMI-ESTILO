# SAMI ESTILO

Proyecto web desarrollado para *SAMI ESTILO*, enfocado en crear una interfaz sencilla y moderna para una tienda de moda.

## Funcionalidades realizadas

* Página principal de bienvenida.
* Botón para *Iniciar sesión*.
* Formulario de *Registro de usuario*.
* Validación de campos.
* Estilo visual en tonos rosa, dorado, crema y negro.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

Este proyecto permite practicar la creación de interfaces, formularios y validaciones básicas usando JavaScript.
